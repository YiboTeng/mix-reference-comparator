# 人声音色、咬字、动态与谐波细分诊断

## 使用范围

进行完整人声对比，或用户要求判断静态/动态 EQ、咬字硬度、压缩密度、分频动态、规则谐波与噪声型亮度时，运行 `scripts/detail_diagnostics.py`。

脚本对两份未对齐音频分别选择高能量片段。不同歌手、歌词、音域、录音和分离算法仍是混杂因素；脚本描述可观测行为，不识别商业插件。

## 高价值固定指标

### 动态频段与音量相关音色

- 统计各频段相对全频能量的中位数及 10–90% 范围。
- 分别计算弱声、普通、强声的频谱形状。
- 长期中位偏差支持静态 EQ；宽分布或只在强弱声出现的偏差更支持 Dynamic EQ。
- `150–600 Hz / 600 Hz–5 kHz` 作为低中频遮蔽代理，不等于某个固定 EQ 频点。

### Presence、Air 与齿音

- Presence 使用 2.5–8 kHz 相对能量。
- Air 使用 12–18 kHz 相对能量。
- 齿音候选要求 5–12 kHz 占比异常且频谱变化较快，只表示事件率。
- 不把齿音候选率直接改写成 De-esser 压缩量；必须听具体 S、SH、CH。

### 咬字与音节包络

- 对检测到的起始点进行对齐，比较字头、主体和 500 ms 内衰减。
- `字头峰值/主体` 较高表示起始峰相对后续音节更突出。
- `辅音高频/元音主体` 高度依赖歌词，只能作为辅助证据。
- 音节主体电平 IQR 可辅助判断 Clip Gain、Vocal Rider 或压缩需求。

### 宏观、微观与分频动态

- 宏观动态使用约 1 秒窗口，描述乐句和长时间电平变化。
- 微观动态使用约 20 ms 窗口，描述字头和短时密度。
- 近峰密度高表示更多活跃短窗贴近高电平区，不等于压缩器型号。
- 分频段 P90–P10 用于定位 Dynamic EQ、De-esser 或多段处理区域。
- 4 倍过采样峰值只作 True Peak 风险近似提示。

### 谐波与噪声结构

- 优先联合解释谐波衰减 dB/oct、5 阶以上谐波份额和频谱平坦度。
- 谐波衰减越不负，表示高次谐波平均延伸更强。
- 高频谐波份额较高且频谱平坦度较低，支持“亮度更贴合规则音高结构”。
- 人声分离、MP3、颤音和叠唱会改变这些数值，不能证明使用饱和或削波插件。

## 条件性或辅助指标

- **持续共振候选**：只有峰值突出且在足够多活跃帧中出现时才提及；不同元音不能直接变成 EQ 处方。
- **句尾全频衰减**：只保留之后至少约 450 ms 几乎没有重新激活的句尾。样本不足时报告“证据不足”。
- **响度相关高频纹理**：可描述强弱声变化，发声力度和元音同样会造成差异。
- **压缩/削波代理**：只描述贴峰、平顶和字头/主体行为，不反推 Attack、Release 或插件名称。
- **短时谱形稳定**：只说明相邻稳定帧变化速度，不证明调音或动态处理。

## 不得写成强结论

- 音高平台、局部波动和颤音代理不能证明 Auto-Tune、Melodyne 或 Retune Speed。
- 共振峰代理不能跨不同歌手、歌词直接比较，也不能决定 Formant 参数。
- 通用谐波 bin 集中度若两者接近，不应强行解释；优先使用衰减斜率和高阶份额。
- 任一条件性检测样本不足时必须明确跳过，不能用零值冒充真实测量。

## 可靠性措辞

- **测量结果**：直接报告指标和方向。
- **强推断**：至少两项高价值指标方向一致，例如低中频遮蔽较强且 Presence 较低。
- **辅助证据**：内容敏感或因果不唯一，例如辅音/元音、响度相关纹理。
- **不可判断**：长句尾样本不足、不同歌手的 Formant、具体调音或商业插件名称。

## 细分图逐子图等级

- D1 动态频段：中高；音量相关音色：中；持续共振：中低；Presence/Air/齿音：中高。
- D2 音节包络：中高；起始 Presence：中；长句尾：按事件数动态标中低或证据不足；辅音/元音与字头代理：中低。
- D3 宏/微动态：高；峰值密度：高；分频动态：中高；压缩/削波代理：中低。
- D4 谐波/噪声组合：中；谐波衰减与响度纹理：中低；局部音高：低；Formant 代理：低。

脚本必须把这些等级写入每个子图标题。若检测样本不足，动态降级为“证据不足”。
