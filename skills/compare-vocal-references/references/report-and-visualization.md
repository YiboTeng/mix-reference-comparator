# 报告与可视化规范

## 子图可信度标注

每个坐标轴或独立面板都必须单独标注，不得只在 PNG 总标题、图注或报告正文中给整图一个等级。统一把标注放在子图标题第二行：

```text
可信度：中高｜可判常驻/偶发；仍受音素影响
```

可信度描述的是“该子图用于当前 A/B 解释和混音决策的可靠程度”，不是算法是否成功运行：

- **高**：直接、稳健的电平或统计测量，主要方向不依赖具体内容。
- **中高**：测量稳健，但存在一个明确且可控制的内容影响。
- **中**：差异可测，因果或跨歌手比较存在明显混杂项。
- **中低**：适合提示检查方向，必须听音或联合其他指标验证。
- **低**：只能作为辅助观察，不进入摘要或处理建议。
- **证据不足**：有效事件/片段不足，不比较、不以零值代替。

一个 PNG 有多个子图时，允许各子图等级不同。报告正文引用某个发现时，必须写该子图的等级或使用同等谨慎的措辞。低可信和证据不足的子图不得支撑“强推断”。

## 必须按此顺序输出

1. 一句话结论。
2. 输入有效性与限制。
3. 紧凑测量表。
4. 直接显示图 1，并紧跟中文解释。
5. 直接显示图 2，并紧跟中文解释。
6. 直接显示图 3，并紧跟中文解释。
7. 当分频段立体声有帮助时直接显示图 4。
8. 运行细分诊断时，依次显示 D1–D4；D4 的低可信项目不得进入摘要结论。
9. 运行高级空间诊断时，依次显示三张空间补充图并解释。
10. 分层诊断：音色、咬字、动态、颗粒、音高质感和空间。
11. 按优先级排列的处理方案。
12. 限制以及还需要用户提供的信息。

## Codex 内直接交付

`reference-set-report.md` 必须是最终报告原件，而不是仅供内部使用的草稿。最终回复不得只给出报告文件路径：

1. 先以 `## 报告正文` 为标题，完整读取并呈现 `reference-set-report.md` 的正文、表格与结论，不得用摘要或节选替代。
2. 报告正文和图片全部呈现完毕后，再以 `## 输出文件` 列出输出目录、`reference-set-report.md`、`reference-set-metrics.json`、`execution-log.json` 和主要 PNG 的绝对路径。
3. 报告正文直接使用 Markdown 渲染，不放进 fenced code block（围栏代码块）。
4. 将报告中的相对图片引用换成绝对路径，并在相应章节直接显示；每张图后继续保留中文解释。
5. 如果最终解释比脚本初稿更完整，先把解释写回 `reference-set-report.md`，再在 Codex 中展示，保证文件版与对话版结论一致。
6. 回复必须自包含；用户不打开任何本地 Markdown 查看器也能读到完整报告。

## 必须生成的图

### 01｜频谱与频段差值

显示两份音频各自高能量片段的音色形状，并在 1 kHz 附近归一化。图中必须明确标注归一化。频段差值定义为“参考减用户混音”。

解释：

- 哪些宽频段由哪份文件占优。
- 哪些差异可能来自歌手或音域。
- 为什么测量差值不能直接当作 EQ 增益。
- 哪些地方优先尝试 Dynamic EQ（动态均衡），而非静态均衡。

### 02｜时间—频率声谱图

两份音频使用相同时长、相同频率范围和相同颜色刻度。

解释：

- 水平谐波线。
- 竖向辅音/瞬态带。
- 上部雾状和断裂纹理。
- 哪些可能是人为处理，哪些可能是分离/Codec 伪影。

### 03｜动态、空间和颗粒

必须包含：

- 活跃 50 ms RMS 分布。
- 核心、主体、句尾和极弱阶段的 Side/Mid 宽度。
- 高频谐波集中比较指标。

解释为什么“再加压缩”未必正确，闪避效果在图上如何表现，以及谐波指标为什么只用于比较而不能当结论。

### 04｜各频段立体声宽度

显示所选片段每个宽频段的 Side/Mid。解释宽度主要在主唱核心、高频效果还是全频范围。

## 高级空间补充图

只在运行 `spatial_diagnostics.py` 时交付：

### S1｜ILD/IPD 时频声像分布

解释亮区是集中在中央、少数离散区域，还是沿左右相位方向连续铺开。不能把高空间熵单独当作混响，因为分离伪影也会铺开分布。

### S2｜左右相干度与非零延迟峰

解释中频相干度、固定短延迟峰的位置和集中程度。尖锐固定峰支持短延迟或复制关系，但移调、调制、双轨和分离会削弱或伪造峰。

### S3｜宽度随音量与 Side 尾部

解释核心到句尾的 Side/Mid 变化，以及停顿后前 300 ms 的 Side 衰减。连续平滑尾部支持空间返回；离散峰支持回声；下一句人声可能污染更长观察窗口。

高级空间结论必须分别写出“紧密/相干”“扩散”“固定延迟”“周期调制”的证据，不要合并成具体插件名称。

## 音色、咬字、动态与谐波细分图

运行 `detail_diagnostics.py` 时交付：

### D1｜音色、共振与高频成分

解释动态频段范围、强声减弱声音色、低中频遮蔽、Presence/Air 与齿音候选。共振候选必须结合出现占比，不直接写成 EQ 增益。

### D2｜咬字、音节包络与停顿

解释字头/主体、辅音/元音和音节主体一致性。只有检测到足够合格长句尾时才解释全频衰减；否则明确写“证据不足”。

### D3｜宏/微动态、分频动态与峰值行为

解释长时间电平、20 ms 短时变化、近峰密度和各频段动态。只描述压缩/削波行为，不反推具体处理器或精确时间常数。

### D4｜谐波、噪声、响度相关纹理与音高

摘要只使用谐波衰减、高阶份额和频谱平坦度。音高平台、颤音和 Formant 代理必须标为低可信，跨歌手时通常不进入处理建议。

## 图片要求

- 生成 PNG，不能只生成 HTML 或交互式图表。
- 中文标签必须使用有效中文字体。
- 每个子图必须显示自己的可信度等级与最主要限制。
- 所有图保持相同颜色映射。
- 坐标轴、单位、图例和标题必须清楚可读。
- 不要把太多小图挤在一张图里；必要时拆成多张 PNG。
- 交付前必须打开图片检查。
- 最终回复用绝对路径直接显示图片，并只链接用户需要的输出文件。

## 面向初学者的讲解结构

每个重要发现都按四步解释：

1. **图上看到了什么。**
2. **听起来通常是什么感觉。**
3. **可能由什么造成。**
4. **应该先试什么可控调整。**

示例：

> 测量结果：所选片段中，你的 150–300 Hz 更高，听起来可能更厚，也可能遮住上方纹理。由于歌手不同，不能把全部差值直接削掉。先尝试 180–280 Hz 的 Dynamic Bell（动态钟形 EQ），最大衰减 2–4 dB，只让它在厚重音节触发。

## 最终文字约束

- 以可执行结论开头。
- 明确区分测量、强推断和假设。
- 先写处理器类别，再写品牌示例。
- 参数范围只能作为起点，不能称为万能数值。
- 写清 A/B Test（开关对比）听什么，以及失败表现。
- 以中文为主体；必要英文术语首次出现时补充中文解释。
- 报告必须自洽，不能要求读者回看之前的工作进度消息。
- 用户未指定输出路径时，运行前明确告知实际默认目录；运行后同时给路径并在 Codex 中展示完整报告。
