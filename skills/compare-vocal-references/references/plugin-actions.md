# 把诊断转换为插件操作

## 音色与遮蔽

### 150–300 Hz 过多

- 先用 Dynamic EQ（动态均衡），Bell（钟形）Q 值 0.8–1.5。
- 初始最大衰减 2–4 dB。
- 只在近讲效应明显或低音音符时触发。
- 失败表现：人声变小、变纸片，元音失去支撑。

### 300–600 Hz 过多

- 围绕听到的箱体感位置，尝试 1–2 dB 宽幅衰减。
- 只有特定音符共振时，优先用窄一些的动态 Resonance Cut（共振削减）。
- 失败表现：辅音仍然暗，但人声主体已经消失。

### 8–12 kHz 不足

- 不要一开始就给全局 High Shelf（高架 EQ）加 5 dB。
- 先控制低中频遮蔽，再通过 Parallel（并联）处理制造规则谐波。
- 然后尝试约 0.5–2 dB 的宽 High Shelf。
- 如果 S、SH 变刺，再使用 De-esser（去齿音器）。

## 制作谐波颗粒

主唱已经很响、很稳定时，优先使用并联轨：

```text
主唱发送
→ High-pass（高通）700–1000 Hz
→ Saturation（饱和）或 Soft Clipping（软削波）
→ 快速 4:1–8:1 压缩
→ 可选：7–11 kHz 去齿音
→ 可选：Low-pass（低通）8–14 kHz
→ 小声返回主唱下面
```

起始设置：

- Drive（驱动）推到单独听并联轨时明显粗糙。
- 返回轨比主唱低 12–20 dB，或从 5–15% Wet（湿声比例）开始。
- 削波/饱和器可用时打开 Oversampling（过采样）。
- Bypass（旁通）前后必须等响度。
- 当主唱咬字和质感增加时停止；出现嗡鸣音高、元音变扁或辅音喷溅就退回。

插件示例仅供选择：

- 饱和：DAW 自带 Saturator/Waveshaper、FabFilter Saturn、Soundtoys Decapitator、Black Box HG-2。
- 削波：DAW 自带 Soft Clipper、KClip、StandardCLIP、Newfangled Saturate。
- DAW 自带或免费替代完全可用；结构和 Gain Staging（增益结构）比品牌更重要。

## 压缩与瞬态形状

如果活跃电平分布已经很窄，不要继续简单增加压缩。保留每个字的开头：

- FET 类：Ratio 4:1，Attack 中等偏快，Release 快，常规最大压缩量约 3–5 dB。
- Leveler/Opto（电平器/光学压缩）阶段：缓慢整理 1–3 dB，可放在 FET 前或后，取决于表演动态。
- 并联轨：把重压缩放到并联，而不是继续压平主唱。

失败表现包括：大舌头、每个字头都一样平、呼吸抽吸和节奏咬字消失。

## 音高校正质感

只有表演环境、听感和图表共同支持时，才建议更强音高校正。现代旋律 Rap 的起始设置：

- Key（调性）和 Scale（音阶）必须正确。
- Retune Speed（校正速度）：约 5–15 ms。
- Humanize/Flex：低到中等。
- 除非有意改变角色，否则保持 Formant（共振峰）。

音高统计不能判断具体调音插件，也不能证明调音制造了颗粒。应在相同饱和链下分别打开/关闭调音做 A/B。

## 齿音

添加谐波时，可考虑两级轻量去齿：

- 饱和前：约 5–8 kHz，刺耳辅音压 2–4 dB。
- 饱和后：约 7–11 kHz，再清理 1–2 dB。

避免使用让整个元音都变暗的宽带去齿。优先 Split-band（分频）De-esser 或 Dynamic EQ。

## 空间与立体声

先根据高级空间诊断区分两类目标：

- **点状/少量副本过强**：降低单个 Doubler 声部返回，削弱副本高频，增加声部数量但降低每声部电平，或在后级加入短而高扩散的 Room/Ambience，使副本不再被单独定位。
- **区域扩散不足**：保持中央干声稳定，把去相关、短空间和调制放在发送返回；不要只把两个副本硬声像到左右。

固定延迟证据、扩散证据和分离伪影必须分开判断。参考若为人声分离文件，不要照抄其绝对 Side/Mid 或相干度。

要实现“核心窄、句尾宽”：

```text
中央主唱
→ 发送到过滤后的 Plate/Room Reverb（板式/房间混响）或 Delay（延迟）
→ 效果返回放 Sidechain Compressor（侧链压缩），由干声触发
→ 唱歌时效果下降，停顿时释放出来
```

起始设置：

- Reverb Pre-delay（混响预延迟）：35–75 ms。
- Reverb Decay（混响衰减）：0.7–1.4 秒，适合较近的现代人声。
- 返回轨 High-pass：250–450 Hz。
- 返回轨 Low-pass：6–10 kHz。
- Ducking（闪避）：唱歌时压低 4–8 dB。
- Release：约 200–500 ms，并根据节奏调整。
- Delay：过滤后的 70–140 ms Slap（短回声），或同步八分/附点八分；Feedback（反馈）8–25%。

响亮主唱核心保持相对窄。主要宽化放在返回轨、叠唱或自动化句尾上，并检查 Mono Compatibility（单声道兼容性）。

## 优先级规则

多个参考时，先处理至少三个独立参考共同支持、方向一致率不低于 75%、且指标可信度为中或更高的偏差。单个参考独有的差异放入“审美选择”，不得排在参考共性之前。若参考少于三个，维持一对一建议并明确它不是行业范围。

第一轮最多给五项操作：

1. 先修正最大的遮蔽失衡。
2. 修正主唱核心与句尾的空间结构。
3. 添加并联规则谐波。
4. 控制新产生的齿音。
5. 等响度 A/B 后再微调明亮度、宽度和响度。
