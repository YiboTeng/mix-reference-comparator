# 高级人声声场诊断

## 使用边界

当用户要求区分点状副本与连续区域，或辨别 Doubler、Haas Delay、Microshift、双轨、Chorus/Ensemble、宽混响和分离伪影时，运行 `scripts/spatial_diagnostics.py`。

该脚本是证据组合工具，不是插件识别器。没有原始单声道干声、湿声单独导出和未分离的参考 Stem 时，只给声场类型和处理类别的概率性判断。

## 核心测量

### 1. Mid/Side 与音量阶段

逐采样点计算：

```text
Mid  = (L + R) / 2
Side = (L - R) / 2
Side/Mid dB = 20 × log10(Side RMS / Mid RMS)
```

按核心、主体、句尾、极弱阶段比较 Side/Mid。句尾比核心更宽支持闪避混响/延迟、发送自动化或尾音叠层，但分离残留也可能在弱段占比上升。

### 2. ILD/IPD 时频声像分布

- ILD（声道间电平差）：每个时频单元中左右幅度之比。
- IPD（声道间相位差）：每个时频单元中左右复数频谱的相位差。
- 紧密亮团支持中央相干或少量稳定声像。
- 沿相位方向连续铺开支持去相关、扩散空间、真实双轨或分离伪影。
- 空间熵越高表示分布越分散，但不能单独证明混响。

### 3. 分频段相干度

Magnitude-squared coherence（幅度平方相干度）衡量左右在各频率上的线性一致程度：

- 中频高相干通常更集中、更像共同中央声源。
- 中频低相干支持双轨、调制、扩散空间或分离残留。
- 高频低相干可能只来自宽效果或编码噪声，不能代表人声主体很宽。

### 4. GCC-PHAT 非零延迟峰

在多个短时窗口中寻找左右声道的非零时延关系：

- 尖锐且稳定的峰支持固定短延迟、复制声部或 Haas 关系。
- 峰位置周期摆动支持 Chorus/调制延迟。
- 峰分散可能来自多声部移调、真实双轨、扩散或分离伪影。
- 多声部移调 Doubler 即使听成几个点，也可能没有单一稳定延迟峰；不要把峰分散直接等同于混响。

脚本排除零点附近再找峰，但中央干声仍会影响结果。`zero_to_offzero_peak_ratio` 高表示共同中央成分仍强。

### 5. Mid/Side 包络关系与停顿尾部

- Side 包络立即、高度跟随 Mid，支持短延迟、Doubler 或紧贴字头的宽化。
- Side 包络的相关峰较宽，支持时间涂抹或多个不同延迟。
- 停顿后 Side 连续平滑衰减支持 Room/Plate 等空间返回。
- 停顿后出现离散次峰支持 Slap/Delay。
- 只解释前 300 ms，避免下一句人声污染尾部。

## 证据组合

分别报告四组分数，范围仅用于同一次 A/B：

- `compact_coherent_evidence_0_to_1`：中央紧密、高相干、相位分布较窄。
- `diffuse_field_evidence_0_to_1`：低相干、相位铺开、空间分布较散。
- `fixed_delay_evidence_0_to_1`：非零延迟峰集中、跨频率相位斜率较线性。
- `periodic_modulation_evidence_0_to_1`：延迟轨迹存在周期变化。

不要跨歌曲库建立绝对阈值，也不要把最高分直接改写成插件名称。至少两项独立观察一致时才使用“强推断”。

## 处理类别的典型证据

| 类别 | 常见证据 | 主要混淆项 |
|---|---|---|
| 固定短延迟/Haas | 集中的非零延迟峰、较稳定的频率相位关系、单声道梳状变化 | 中央干声、分离相位 |
| Microshift/Doubler | 短延迟证据、相干度下降、Side 包络紧跟 Mid；调制时峰会散 | Chorus、分离伪影 |
| Chorus/Ensemble | 延迟轨迹周期摆动、相干度随时间变化 | 多声部 Doubler |
| 真实双轨 | 低相干、延迟不固定、音节时序和包络差异不规则 | 调制 Doubler |
| 宽混响 | 相位连续铺开、停顿后 Side 平滑衰减、句尾变宽 | 分离残留、密集延迟 |
| Slap/Delay | 停顿后离散次峰、固定时间重复 | 早期反射 |
| 人声分离伪影 | 低相干、高空间熵、不规则相位与断裂纹理 | 真实扩散空间 |

## 报告措辞

优先写：

> 测量结果：参考的中频相干度更低、IPD 分布更铺开，支持“区域型声场”；同时约 4 ms 处有短延迟证据，说明扩散背景中可能叠有极短宽化。由于参考来自人声分离，该延迟和低相干也可能包含算法伪影。

避免写：

> 参考一定用了某款 Microshift 或混响插件。

## 声场图逐子图等级

- S1 每个输入的 ILD/IPD 面板：中；分离伪影也可能制造相位铺展。
- S2 分频相干度：中高；非零延迟峰：中低。
- S3 音量阶段宽度：中；Side 尾部：有足够停顿事件时中低，否则证据不足。

每个输入面板和每个坐标轴必须在自己的标题第二行显示等级与限制，不能只给整张 PNG 一个声场可信度。
