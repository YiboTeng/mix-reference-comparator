# 多参考人声对比

## 目录

1. 分析对象
2. 参考集设计
3. 统计规则
4. 输出结构
5. 结论边界

## 1. 分析对象

固定一条“待评估人声”，与一个或多个“参考人声”比较。参考可以是处理后独唱、正式 Stem 或人声分离音轨，但不能把分离音轨称为原始干声。

每个参考先与待评估人声完成一对一基础、细节和按需空间诊断；多参考汇总只建立在这些一对一结果之上。

## 2. 参考集设计

- 一个参考：只能描述一对一差异，不能称为行业共性。
- 两个参考：可以发现初步一致方向，但不能稳定定义正常范围。
- 三至四个独立参考：可以用中等可信度讨论小型参考集共性。
- 五个以上风格、音域和用途匹配的独立参考：可以用中高可信度讨论参考区间；不能升级为绝对行业标准。
- 重复文件、同一母版的不同编码、同一首歌的相邻切片不能当作独立参考。

优先保证风格、声部、音域、性别表达、制作年代和目标用途匹配。参考数量不能补偿严重的样本错配。

## 3. 统计规则

使用参考中位数描述中心。三个以上参考使用四分位区间描述常见范围；一至两个参考只显示最小—最大范围。

“参考共性”必须同时满足：

1. 至少三个有效参考。
2. 至少 75% 参考相对待评估人声指向同一方向。
3. 待评估值超出参考四分位区间，并超过该指标的实际差异门限。
4. 指标本身不是低可信或证据不足。

稳健偏差用于跨单位排序，不是物理量：

```text
稳健偏差 = (待评估值 − 参考中位数) / max(IQR / 1.349, 指标实际差异门限)
```

不要简单平均多个参考音频或频谱。中位数用于中心，区间用于保留审美差异，离群度用于识别参考个性。

## 4. 输出结构

`compare_reference_set.py` 生成：

- `reference-set-metrics.json`：输入、参考集可靠性、逐指标参考分布与稳健偏差。
- `reference-set-report.md`：参考共性、最大差异、限制和一对一报告索引。
- `R1_levels_and_timbre.png`：绝对电平/动态轮廓与频段参考包络。
- `R2_dynamics_and_texture.png`：动态范围与音色/纹理稳健偏差。
- `R3_spatial_reference_field.png`：不同电平阶段宽度与声场位置。
- `R4_consensus_and_outliers.png`：参考集位置与参考离群度。
- `pairwise/<reference>/`：每个参考的完整一对一基础、细节和空间输出。
- `execution-log.json`：可复现的子分析器命令和运行结果。

每个独立子图必须各自显示可信度和主要限制。R4 的可信度随有效参考数量变化；参考不足时必须显示“证据不足”。

## 5. 结论边界

- 多数参考共同拥有某个测量特征，不证明它们使用了同一插件。
- 分离参考共同出现的宽度、音乐噪声或瞬态涂抹，可能是分离算法共性，不是混音行业标准。
- 参考离群不等于质量差，只说明它体现更强的个性或与当前参考集不匹配。
- 最终处理建议必须回到一对一图和听感验证，并在等响度下逐项 A/B。
