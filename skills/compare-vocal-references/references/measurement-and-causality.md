## 1. 比较有效性

先给每个输入分类：

- **原始干声**：保留话筒、前级和房间特征，通常没有混音处理。
- **处理后独唱**：可能包含音高校正、剪辑、压缩、EQ、饱和、发送效果或人声总线处理。
- **人声 Stem（分轨）**：可能包含叠唱、Ad-lib（即兴副声）、效果、自动化和人声总线限制器。
- **Source Separation（人声分离）文件**：同时包含原混音处理、分离算法错误以及可能的伴奏泄漏。

不同歌手和旋律会大幅改变绝对频谱，所以不能安全地直接做频谱相减。应独立选择各自持续高能量片段，并只在稳定中频附近归一化，以比较音色“形状”。不能把频段差值直接当作 EQ 配方。

Codec（编码）差异在约 12–16 kHz 以上和瞬态附近尤其明显。MP3 再经过人声分离可能形成水声、孔洞、竖向亮带和人工高频纹理。

## 2. 核心测量

### 绝对电平

- **Integrated LUFS（综合响度）**：整段节目响度，会受静音比例和编曲影响。
- **Sample Peak（样本峰值）**：最大样本幅度；除非明确过采样，否则它不是 True Peak（真实峰值）。
- **RMS（均方根电平）**：平均能量；必须结合 LUFS 使用。
- **Crest Factor（峰均比）**：峰值减 RMS。数值较低通常代表压缩/削波更密，但静音和瞬态也会影响结果。
- **活跃 50 ms RMS 分布**：显示音节电平集中位置和变化范围，比单一 RMS 更适合判断人声压缩状态。

必须指出哪份文件本来就更响。主观比较音色前先做等响度匹配。

### 音色平衡

使用 Welch PSD（功率谱密度）获得稳定长期估计。关注这些宽频段：

- 20–80 Hz：低频振动、伴奏泄漏。
- 80–150 Hz：低音人声基频重量。
- 150–300 Hz：温暖、近讲效应、浑浊。
- 300–600 Hz：主体、箱体感。
- 600 Hz–1.2 kHz：中频主体。
- 1.2–2.5 kHz：咬字。
- 2.5–5 kHz：Presence（存在感）与辅音边缘。
- 5–8 kHz：齿音和明亮谐波。
- 8–12 kHz：上部齿音、激励、颗粒和分离残留。
- 12–20 kHz：Air（空气感）、编码/分离影响和噪声。

必须结合歌手音域和音素内容解释。只有部分音符或音节过量时，优先推荐 Dynamic EQ（动态均衡）。

### 声谱图

在时间—频率声谱图中：

- 横向、等间距亮线多为谐波。
- 竖向宽频亮带多为瞬态、爆破音、辅音或编辑边界。
- 上方弥散雾状纹理可能是气息、噪声、Exciter（激励）、混响、编码残留或分离噪声。
- 断裂、水状的谐波边缘经常与人声分离或有损编码有关。

不要比较随机选出的静音偏多片段。自带分析器会为两份输入分别挑选最强连续窗口。

## 3. 颗粒感与谐波结构

“颗粒感”是听感形容词，不是处理器名称。拆成：

1. **规则谐波能量**：跟随音高的高频泛音，可能来自饱和、削波、明亮录音、非线性压缩、共振峰特征或强音高校正。
2. **无声纹理**：气息、辅音、激励、噪声或失真产物。
3. **快速包络变化**：激进压缩、削波、Gate（门限）、剪辑或人声分离制造的粗糙边缘。
4. **遮蔽平衡**：即使高频相同，过多低中频仍可能让它听不见。
5. **人工残留**：人声分离和 Codec 伪影会产生颗粒，但并不代表原混音真的有这种处理。

脚本会在可信有声音框里估计：5–10 kHz 能量中，有多少靠近基频整数倍。此值只用于 A/B 比较。音高估计、窗长、颤音、叠唱、分离算法和频谱泄漏都会影响结果。

音高稳定性可以支持“可能有音高校正”的假设，但不能证明使用了 Auto-Tune、Melodyne、手动画线或具体 Retune Speed（校正速度）。演唱方式也可能产生相似统计。

## 4. 音色、咬字与动态细分

完整对比时运行 `scripts/detail_diagnostics.py`，并阅读 `detail-diagnostics.md`。优先使用：

- 各频段中位数与 10–90% 范围，判断常驻偏色还是偶发音素。
- 强声、普通、弱声音色，判断静态或动态 EQ。
- 字头/主体、音节主体 IQR、宏观与微观动态，判断压缩密度和电平整理需求。
- 分频段 P90–P10，定位 Dynamic EQ、De-esser 或多段动态处理。
- 谐波衰减、高阶谐波份额和频谱平坦度，区分规则泛音与噪声型亮度。

辅音/元音、响度相关纹理、音高和 Formant 都受表演内容影响，必须降级为辅助或不可判断。长句尾样本不足时不得用零值代替真实衰减。

## 5. 立体声与空间

同时查看全文件相关度和按音量分组的 Mid/Side（中/侧）比值。

- 相关度接近 +1：左右声道非常相似，Mono Compatibility（单声道兼容性）通常较好。
- 相关度较低：可能更宽、左右去相关、有效果/叠唱，也可能是分离残留。
- Side/Mid 接近 0 dB：侧声道能量接近中间声道，听感很宽。
- Side/Mid 越负：越窄、越集中在中央。

按音量阶段测量：

- 核心：距强人声 0 到 −6 dB。
- 主体：−6 到 −15 dB。
- 句尾：−15 到 −30 dB。
- 极弱部分：−30 到 −45 dB。

“核心窄、句尾宽”支持 Ducking（闪避）混响/延迟、效果自动化或尾音叠层的推断，但不能唯一证明某一种技术。人声分离也可能把残余伴奏集中到 Side。

还要按频段测量 Side/Mid。只有高频很宽时，更可能是立体声混响、Microshift（微移调宽化）、叠唱、激励或分离残留，而不是整条主唱被全频宽化。

## 6. 高级声场诊断

Side/Mid RMS 只能说明左右差异能量有多少，不能区分 Doubler、双轨、Microshift、延迟、混响或分离伪影。用户追问“几个点”与“一整片区域”的差异时，运行 `scripts/spatial_diagnostics.py`，并完整阅读 `spatial-field-diagnostics.md`。

至少联合解释：

- ILD/IPD 时频声像分布是否紧密聚类或沿相位连续铺开。
- 300 Hz–5 kHz 左右相干度是高而稳定，还是低而分散。
- GCC-PHAT 是否出现固定、尖锐的非零延迟峰。
- Side 包络是立即跟随 Mid，还是延后并被时间扩散。
- 主唱停顿后 Side 是快速消失、离散重复，还是连续衰减。

把“紧密/相干证据”“扩散证据”“固定延迟证据”和“周期调制证据”分开。多声部移调 Doubler 可能没有稳定延迟峰，但仍听成少量点状副本；极短延迟也可能埋在扩散声场里，不应凭一个指标命名处理器。

## 7. 因果置信度

使用三级标签：

- **测量结果**：“所选片段中，参考在 8–12 kHz 的相对能量约高 5 dB。”
- **强推断**：“响亮核心很窄而句尾明显变宽，符合闪避或自动化发送效果的表现。”
- **假设**：“可能使用了磁带型饱和器或 Soft Clipper（软削波器）。”

至少两项独立观察一致时才能使用“强推断”。单独看到 8–12 kHz 较高不能证明饱和；如果规则谐波也更多、高频密度更高且有声音高稳定，非线性谐波生成才更可信。

## 8. 常见误判

- 静音比例导致综合统计不可比。
- 音域不同会让低中频频段大幅移动。
- 人声分离可能削弱基频并夸大残留。
- 立体声分离算法可能凭空制造 Side 能量。
- MP3 低通可能被误判成 De-essing（去齿音）。
- 参考即使被分离出来，也仍可能保留原母带限制器影响。
- 以 1 kHz 归一化会在视觉上放大其他频段，图中必须明确标注。
- 数值差异大，不代表应该使用同样幅度的 EQ。
- 把“延迟峰分散”直接当成宽混响；多声部移调或调制 Doubler 也会分散延迟峰。
- 把低相干、高空间熵直接当成真实扩散；人声分离也会制造相同结果。
